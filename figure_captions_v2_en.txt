Figure V2-1 (figv2_01_workflow). Study design. Both dataset versions follow the same pipeline: cleaning and deduplication before splitting, five stratified splits, per-split tuning on validation data, SHAP ranking on training data only, and a single test evaluation. Post hoc analyses, the replication on the improved dataset and the additional ensemble models are shown below the main pipeline.

Figure V2-2 (figv2_02_feature_selection_baselines). Feature-selection criteria compared on the original dataset (post hoc analysis). Macro-F1 of a Random Forest trained on the k features ranked highest by SHAP, by the impurity-based importance of the full model (MDI) or drawn at random (one subset per split and k). Large markers show the mean and error bars the standard deviation over five splits; small points are single splits; the dashed line is the full model. (a) All 15 classes; (b) the 12 classes with at least 100 flows.

Figure V2-3 (figv2_03_topk_original_vs_improved). Effect of reducing the Random Forest to the top-k SHAP features on the original and the improved dataset. Mean and standard deviation over five splits; All denotes the full model (69 features in the original, 77 in the improved dataset). (a) Macro-F1 over all classes (15 and 16 classes); (b) Macro-F1 over the classes with at least 100 flows (12 and 11 classes). The ranking is computed on training data only.

Figure V2-4 (figv2_04_ablation_per_class). Ablation on the original dataset (post hoc). Change in the F1 of each class (mean over five splits) when a Random Forest with the hyperparameters of the full model is trained without Destination Port, without the six features flagged as shortcut candidates by Engelen et al. (Fwd Header Length, Total Fwd Packets, min_seg_size_forward, Init_Win_bytes_forward, SYN Flag Count, Bwd Packet Length Mean), or without both. The number in brackets is the F1 of the full model. Heartbleed, Infiltration and Web SQL Injection have only 2 to 5 test flows per split, so their changes are unstable.

Figure V2-5 (figv2_05_per_class_f1_original_vs_improved). Class-wise F1 of the full Random Forest on the original and on the improved dataset (mean over five splits). Class names are matched between the two versions; Infiltration-PortScan exists only in the improved dataset. The largest differences between the two versions are seen for the classes with the lowest F1 on the original dataset (for example Bot, Web XSS and Web Brute Force); Heartbleed, Infiltration and Web SQL Injection have only 2 to 5 test flows per split.

Figure V2-6 (figv2_06_per_class_f1_topk_improved). Class-wise F1 of Random Forests trained on the top-k SHAP features of the improved dataset (mean over five splits). Reducing the model to 5 or 10 features mainly removes the ability to separate the two port-scan classes (Infiltration-PortScan and PortScan); almost all other classes stay near 1. Web SQL Injection has only 2 to 3 test flows per split.

Figure V2-7 (figv2_07_confusion_rf_improved). Row-normalised confusion matrix of the full Random Forest on the improved dataset, summed over the test partitions of the five splits. Numbers are percentages of the true class; off-diagonal cells are shown from 0.5 %. Almost all errors occur between PortScan and Infiltration-PortScan. Classes with very few test flows (Heartbleed, Infiltration, Web Brute Force, Web SQL Injection, Web XSS) have unstable rates.

Figure V2-8 (figv2_08_shap_importance_top15). Global SHAP importance of the 15 most important features of the full Random Forest (mean over five splits; error bars show the standard deviation). The importance is the mean absolute SHAP value over a class-balanced sample from the training partition and over all output classes. (a) Original dataset; (b) improved dataset. Hatched bars mark the features flagged as shortcut candidates by Engelen et al. (2021).

Figure V2-9 (figv2_09_confusion_rf_original). Row-normalised confusion matrix of the full Random Forest (69 features) on the original dataset, summed over the test partitions of the five splits. Numbers are percentages of the true class; off-diagonal cells are shown from 0.5 %. Classes with a recall below 90 %: Web Brute Force (79 %), Infiltration (76 %), Bot (75 %), Web XSS (36 %), Web SQL Injection (13 %). Classes with very few test flows (Heartbleed, Infiltration, Web SQL Injection) have unstable rates.

Figure V2-10 (figv2_10_confusion_rf_class_weighted_original). Row-normalised confusion matrix of the class-weighted Random Forest (69 features) on the original dataset, summed over the test partitions of the five splits. Numbers are percentages of the true class; off-diagonal cells are shown from 0.5 %. Classes with a recall below 90 %: Infiltration (88 %), Web Brute Force (75 %), Web SQL Injection (53 %), Web XSS (44 %).

Figure V2-11 (figv2_11_shap_top20_stability_original). Stability of the SHAP top-20 feature set of the full Random Forest on the original dataset across the five splits (mean pairwise Jaccard index = 0.84).
